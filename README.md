# Kumone

这是 [missuo/kumone](https://github.com/missuo/kumone) 的个人 fork，用于个人定制。感谢 missuo 和上游贡献者。

仅支持 Apple 芯片 Mac（arm64），系统要求 macOS 15 或更新版本。
